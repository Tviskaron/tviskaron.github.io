# tviskaron.github.io

Personal academic page built with [Astro](https://astro.build/).

## Local development

Requires [Node.js](https://nodejs.org/) >= 22.

```bash
make install   # install dependencies
make dev       # start dev server at http://localhost:4321
make build     # build static site to dist/
make preview   # build + preview production build
make clean     # clear build cache
```
